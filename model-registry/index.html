Shiso Model Registry

Model recipes and the index served to shiso pull.

This site is a static host of the registry repository. There is nothing to browse here; the machine-readable artifacts are:

  • /registry/v1/index.json — the model index
  • /registry/v1/models/ — per-model manifests
  • /recipes/ — the authored recipe sources

Point a client at this host with --registry-url or SHISO_REGISTRY_URL; it appends /registry/v1/ itself.
