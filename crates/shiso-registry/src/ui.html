Measure Throughput on This Device

      

      

        Start shiso serve <name>:<variant> (release build) for an installed variant, then run the bench here.
        What is measured follows the recipe's task: tokens a second for chat, milliseconds a decision, seconds an image, and the real-time multiple for transcription.
        The record is written to benchmarks/<model>/<variant>/<device>.json; commit it and rebuild to publish.
